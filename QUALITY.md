# Quality standard

Acest proiect important este urmărit după același standard public de livrare.

## Release gates

- [ ] Fluxul principal este verificat pe mobil (360 px) și desktop
- [ ] Navigarea cu tastatura și focusul vizibil sunt verificate
- [ ] Preferința reduced motion este respectată
- [ ] Datele persistente și resetarea sunt testate
- [ ] Demo-ul GitHub Pages și linkurile externe funcționează
- [ ] README și CHANGELOG descriu versiunea curentă
- [ ] Capturile și metricile publicate au sursă și dată

## Evidence labels

- **Measured** — rezultat obținut cu un instrument sau test repetabil
- **Observed** — comportament verificat manual
- **Estimated** — ipoteză declarată, nu rezultat
- **Pending** — încă nemăsurat
